# Banana Bay

A tiny tropical island with three animated monkeys collecting bananas. Drawn entirely with a procedural fragment shader.

## Run

Open `index.html` in a browser with WebGL 2 support. The page is self-contained and needs no build tools or external assets.

- Pause or restart the animation.
- Adjust the animation speed.
- Hold and drag on the scene to move the sun.
- Copy or download the Shadertoy source.

## GitHub Pages

Publish the root directory of the `main` branch through GitHub Pages. The `.nojekyll` file lets Pages serve the static files directly.

## Shadertoy

Paste `banana-bay.glsl` into the Image pass. No channels, textures, or extra buffers are required.
